# 万缕 · Long Memory V0.8.3 · Oil UI

独立的 SillyTavern 前端长期记忆 / 状态 / 关系 / 故事事件扩展。

> 聊天正文是事实，记忆是整理，状态是推演，召回是选择，事件是故事单位。

## V0.8

- 时间轴回看：事件可显示对应聊天楼层，点击“回看这一段”会尝试载入并滚动到原楼层，同时短暂高亮目标消息。
- 故事时间轴与关系历史继续独立保存于浏览器 IndexedDB。
- AI整理统一入口：长期记忆 / 故事事件 / 角色状态 / 人物关系可一次选择。
- AI整理范围：最近 N 条、24 条、48 条、全部聊天。
- 移动端 UI 重构：仪表盘、AI 服务/模型显示、关系历史、时间轴、可读状态卡片、后台工具折叠。
- 当前 AI 服务不单独管理 API Key，跟随 SillyTavern 当前 API / 模型；扩展自己的持久化数据仍使用浏览器 IndexedDB。
- 保留 V0.5 任务队列、诊断、语义召回；保留 V0.6 记忆合并；保留 V0.7 事件与关系历史。

## 安装

SillyTavern 的第三方扩展安装需要 Git 仓库地址。将本目录的全部文件放到 Git 仓库根目录（确保 `manifest.json` 位于根目录），然后在 SillyTavern → Extensions → Install Extension 中粘贴仓库地址。

## 数据安全

万缕默认只在浏览器 IndexedDB 保存自己的数据，不依赖 BaiNiaoData，也不需要额外 Server Plugin。

## 重要说明

“回看”不会删除、截断或重写聊天正文；它只尝试载入历史消息并滚动到对应楼层。若酒馆当前版本未向扩展暴露加载历史消息的方法，万缕会使用聊天页面现有的“显示更多消息”入口作为兼容回退。


## V0.8.2 · Oil UI 缱绻手札

首页融合书页档案与索引导航，新增「总览、记忆、时间轴、关系、设置」五个移动端标签。保留 V0.8.1 线轴悬浮球、独立 API 配置和既有记忆功能。此为待酒馆实测的 UI 集成版；更新前请备份。

## V0.8.3 · 生命周期与剧情唤忆（待 SillyTavern 手机实测）

- 修复正式扩展停用/启用：新增 `enable` 钩子，重新绑定聊天事件监听；停用时解除监听、暂停后台排队任务并清空万缕专属提示词。
- 修复对 SillyTavern `getContext().eventTypes` 的兼容读取，并修正 Oil UI 中未定义变量导致的初始化报错。
- 生成前监听 `GENERATION_AFTER_COMMANDS`，仅从**当前聊天** IndexedDB 读取已保存的有效记忆，使用 `setExtensionPrompt` 临时注入角色的生成上下文。**不往真实聊天楼层插入系统消息、不更改酒馆原始正文。**
- 中文关键词检索支持物品和事件的简短提及；新提取的记忆增加 `keywords`，合并记忆继承原关键词。旧有记忆无需迁移，仍可以依据文本召回。
- 只召回与当前文本有主题证据的记忆，避免高重要性但无关的旧事误入；仅玩家知晓（`PLAYER_ONLY`）或系统专用记忆不会提供给角色生成。
- 保留「设置 → 生成前召回并注入」开关、召回数量和注入字符限制。不增加新的外部 API 调用；召回是本地数据库检索。

### 推荐手机端验收

1. 更新前进入万缕「设置与维护 → 导出备份」，妥善保存当前聊天数据。
2. 在测试聊天中整理一段关于具体物品（例如「玉佩」）的事实，查看「记忆档案」是否有对应记录。
3. 将该事件移出短期上下文后，在新一轮聊天提及「玉佩」，检查实际发送给模型的提示词是否包含对应 `wanlv_memory` 区块，并确认正文自然参考该经历。
4. 测试无关话题、切换角色、停用后生成，以及连续停用/启用 5 次。验证不串记忆、不重复注入、不新增或改写聊天楼层。
5. 新版本只进行静态检查与回归测试代码准备；在真机和实际 SillyTavern 环境验证前，不应认为已完整通过兼容性测试。
